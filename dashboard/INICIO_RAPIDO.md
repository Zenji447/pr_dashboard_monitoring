# 🚀 Inicio Rápido - Gestión de Ramas

## ⚡ Empezar en 3 Pasos

### 1. Abrir el Dashboard
```
http://localhost:5000
```

### 2. Ir al Tab de Ramas
```
Click en "🌿 Ramas"
```

### 3. ¡Listo!
Ya puedes gestionar tus ramas visualmente.

---

## 📝 Tareas Comunes

### Agregar Nueva Rama

```
1. Click "➕ Agregar Rama"
2. Nombre: "tu-rama"
3. (Opcional) Configurar reglas
4. (Opcional) ☑ Agregar a auto-aprobación
5. Click "Guardar Rama"
```

**Tiempo:** 30 segundos

---

### Configurar Reglas de una Rama

```
1. Buscar la rama en la tabla
2. Click "⚙️ Reglas"
3. Modificar configuración
4. Click "Guardar Cambios"
```

**Tiempo:** 1 minuto

---

### Agregar/Quitar Auto-Aprobación

```
1. Buscar la rama en la tabla
2. Click "🔔 Agregar Auto-Apr." o "🔕 Quitar Auto-Apr."
3. ¡Listo!
```

**Tiempo:** 2 segundos

---

### Eliminar Rama

```
1. Buscar la rama en la tabla
2. Click "🗑️ Eliminar"
3. Confirmar
```

**Tiempo:** 5 segundos

---

## 🎯 Ejemplos Rápidos

### Ejemplo 1: Nueva Rama de Release

```
Nombre: releaseproyecto/r7
Patrón de Release: r?7[.\-]\d+
Sprints: sp71, sp72
☑ Agregar a auto-aprobación
```

### Ejemplo 2: Rama de Hotfix

```
Nombre: hotfix/production
Warning: ⚠️ PR hacia PRODUCCIÓN - revisar con cuidado
☐ Agregar a auto-aprobación (revisar manualmente)
```

### Ejemplo 3: Rama Temporal

```
Nombre: feature/experimental
Warning: Rama experimental - sin validaciones estrictas
☐ Agregar a auto-aprobación
```

## 🆘 Ayuda Rápida

### ¿No ves el tab "🌿 Ramas"?
- Refresca la página (Ctrl + Shift + R)
- Verifica que el servidor esté corriendo

### ¿Error al guardar?
- Verifica que el nombre no esté vacío
- Verifica que la rama no exista ya
- Verifica tu API Key
